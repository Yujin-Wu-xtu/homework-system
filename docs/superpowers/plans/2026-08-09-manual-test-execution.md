# 在线作业系统手工测试执行计划与台账

> **⚠️ 已废弃（2026-08-10）：** 本计划基于旧版功能编写、用例过于繁琐，且系统已新增课程划分（选修/必修）、树形批量选人、管理层级左树右表、分页与每页条数、管理员首页、作业关闭、学生端富文本答题等功能。**请改用** `docs/superpowers/plans/2026-08-10-manual-test-execution-v2.md`。本文件保留备查，不再作为执行依据。

> **范围：** 本文件用于本地启动系统后的手工功能、安全和浏览器验收测试。所有结果必须以本轮实际操作为准；未执行项保留“未执行”，不得补填为通过。

**目标：** 以一条完整的“管理员准备数据 → 教师布置作业 → 学生提交 → 教师评分 → 学生查看结果”链路，验证三角色核心功能、安全边界和可用性，并形成截图证据。

**测试策略：** 先做不修改数据的冒烟测试；之后只使用名称/账号带 `TEST-` 前缀的测试数据；最后做跨角色闭环和安全检查。每完成一条用例，立即填“实际结果”和截图文件名。

**工具：** Windows 浏览器（优先 Chrome/Edge）、本项目 Maven Wrapper、MySQL/XAMPP、系统内置前端与 Knife4j（`http://localhost:8080/doc.html`）。
