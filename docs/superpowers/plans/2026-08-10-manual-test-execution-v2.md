## 四、教师（T）

### T-1 新建必修教学班 + 拉自然班
教学班管理 → 新建教学班，**类型选"必修"**，名称 `TEST-必修班` → 从"自然班级"勾选 2024级软件工程1班。
**预期：** 建班成功；学生列表显示该班 13 名学生；**不能**用"自由选学生"（选修专属）。

### T-2 新建选修教学班 + 树形批量选人（新，重点）
教学班管理 → 新建教学班，**类型选"选修"**，名称 `TEST-选修班` → 点"学生"。
**预期：** ①弹窗左侧是选人树，层级=年级→学院→专业→班级→学生，默认展开；②勾选一个班级节点（如"2024级计算机科学1班"）→ 右侧"本次勾选"实时显示该班全部学生（含班级列）；③也可只勾选单个学生；④点"加入选中（N 人）" → 移到"已加入"列表；⑤刷新弹窗 → 已加入的学生节点显示灰色"已加入"不可重复勾选；⑥点"移出" → 学生从已加入移除、树节点恢复可勾选。

### T-3 必修班与选修班边界
1. 在必修班（T-1）学生弹窗 → 确认**没有**树形选人区（只有自然班学生列表）
2. 在选修班（T-2）的"组建班级"→ 尝试勾选自然班级
**预期：** 必修班不能自由选人；选修班不能按自然班拉取（后端拒绝并提示）。

### T-4 布置作业（富文本应用题 + 客观题）
布置作业 → 选 `TEST-选修班`，标题 `TEST-选修课作业`，截止设为未来；题目选：1 道单选 + 1 道应用题（带富文本题干）→ 发布。
**预期：** 发布成功；作业管理列表出现该作业，提交情况显示被拉入的 2 名学生均为"待提交"。

### T-5 作业编辑 + 关闭（新）
作业管理 → 编辑该作业（改描述/截止时间）→ 保存 → 点"关闭" → 确认。
**预期：** 编辑生效；关闭后作业状态变"已关闭"；关闭后学生端不能再提交（见 S-4）。

### T-6 提交情况 + 成绩导出

**预期：** 提交情况列表/答案查看正常；Excel 可下载且含学生/分数/提交时间列。

**预期：** 单选自动得分；应用题人工得分后总分正确；学生端结果页富文本答案正常渲染、显示分数与评语。
